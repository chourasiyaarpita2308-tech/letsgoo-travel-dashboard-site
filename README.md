# Letsgoo Travel Dashboard

A browser-only India travel planner. No Node.js, npm, database, or installation is required.

## Run

Open index.html in a browser. Public weather and OpenStreetMap data load when online; the app falls back to local sample content.

## Features

- India destination discovery, famous-place photography, map pins, and walkable suggestions
- Weather forecast, INR budget planning, hotel-price demo alerts, and a timed day planner
- Local-only friend pins, profile, and IndexedDB photo journal
- Animated Three.js Earth landing scene with a CSS fallback

Trips, pins, schedules, profile data, and photos are stored in this browser on this device. They are not synced or uploaded. Hotel prices, reviews, and some service listings are demo or map-provider data. Food links open maps or listed businesses; checkout, live parking availability, friend sync, and secure online accounts are not provided.

The 3D scene, fonts, map tiles, landmark photography, and live weather require an internet connection. No terminal commands are needed.
